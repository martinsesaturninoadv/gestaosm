# Gestão SM: sistema de gestão do escritório

Sistema próprio de gestão para o escritório Martins & Saturnino Advocacia.

| Arquivo | Descrição |
|---|---|
| `ms_gestao_escritorio_v4.html` | **Protótipo do sistema completo**: painel, agenda e prazos, tarefas, clientes, processos, documentos e modelos, CRM de atendimentos, financeiro, relatórios e configurações |
| `docs/ESBOCO_SISTEMA.md` | Esboço do sistema: módulos, modelo de dados, arquitetura para produção, segurança/LGPD, integrações e fases |
| `ms_advocacia_saas_v3.html` | Protótipo anterior, focado em salário-maternidade |

## Como usar o protótipo

1. Baixe `ms_gestao_escritorio_v4.html` e abra-o no navegador (Chrome, Edge, Safari, Firefox).
2. Ele já vem com **dados fictícios** para demonstração. Tudo pode ser criado, editado e excluído.
3. As alterações ficam salvas **apenas no navegador** em que foram feitas. Em *Configurações* dá para exportar/importar backup, restaurar o exemplo ou começar com o sistema vazio.

> Não use o protótipo com dados reais de clientes em computador compartilhado: ele não tem login nem criptografia. Para uso real, veja a seção 3 do esboço.
